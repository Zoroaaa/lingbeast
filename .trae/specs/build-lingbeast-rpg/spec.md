# 灵兽录（暂名）——单机灵兽收集 RPG 规格

## Why
用户想要“仙剑 / 宝可梦 / Q宠大乱斗 / 泰拉瑞亚”这一脉络下的单机网页游戏。这四者的交集是「2D 探索 + 回合制战斗 + 收集养成」。首版据此收束为一个核心循环，避免一次性铺开商业级体量导致做不完。

## What Changes
- 新建一款网页游戏，无外部美术素材、双击 `index.html` 即可本地游玩。
- 核心循环：场景探索 → 遇敌进入回合制战斗 → 击败后结契收服 → 升级成长 → 推进主线剧情。
- 首版内容边界：3 个场景、6 种可收服灵兽 + 3 个关隘 Boss、3 段主线剧情、1 个结局。
- 存档双轨：未登录时仅写 `localStorage`；登录后自动同步至云端，实现跨设备续玩。
- 部署形态为 Cloudflare Workers（静态资源 + `/api/*`），数据落在 D1。
- 视觉基调为水墨仙侠：宣纸底色、墨色山脊、单一强调色「灵玉青」、宋体标题、无卡片式界面。
- **BREAKING**：无（全新项目）。

## Impact
- 影响能力：场景探索、回合制战斗、灵兽收集与成长、剧情推进、离线存档、账号与云存档、云端部署、视觉与动效系统。
- 影响代码：`d:\user\lingbeast-rpg\` 下新建
  - `public/index.html`、`public/style.css`、`public/game.js`、`public/cloud.js`（经典 script，保证 `file://` 也能跑）
  - `src/index.js`（Worker 路由与 API）、`schema.sql`（D1 表结构）、`wrangler.jsonc`（部署配置）

## 视觉与体验方向
- **视觉论点**：一张会呼吸的宣纸。墨色层次承担空间，灵玉青只用于“可交互/灵性”信息；所有界面靠留白、字号与分隔线组织，不用卡片。
- **内容结构**：标题海报 → 世界探索 → 战斗 → 结局；四个界面各自只承担一个职责。
- **交互论点**：① 标题页墨迹晕开的入场；② 遇敌时画面墨色压暗、镜头推近的转场；③ 战斗中伤害飘字与血条的缓动收束。

## ADDED Requirements

### Requirement: 标题与开场
系统 SHALL 在首次进入时呈现全屏标题海报，并可开始新游戏或继续存档。

#### Scenario: 首次进入
- **WHEN** 玩家打开页面且本地无存档
- **THEN** 显示游戏名、副标题与「入山」按钮，隐藏「续前缘」

#### Scenario: 存在存档
- **WHEN** 本地存在存档
- **THEN** 额外显示「续前缘」，点击后恢复上次场景、队伍与进度

### Requirement: 场景探索
系统 SHALL 提供基于瓦片网格的 2D 场景，玩家可用方向键/WASD 或屏幕方向键移动，撞到障碍不可穿越。

#### Scenario: 移动与阻挡
- **WHEN** 玩家朝山石/水岸方向移动
- **THEN** 角色停在原地，不穿过障碍

#### Scenario: 场景切换
- **WHEN** 玩家踏入场景出口并满足解锁条件
- **THEN** 播放墨色转场，加载下一场景，角色出现在对应入口

#### Scenario: 触发遭遇
- **WHEN** 玩家在草丛/灵气的可遇敌区域移动达到步数阈值
- **THEN** 播放遇敌转场并进入战斗，敌方为当前场景的灵兽池随机抽取

### Requirement: 回合制战斗
系统 SHALL 提供指令式回合制战斗，指令包含「术法」「结契」「丹药」「遁走」。

#### Scenario: 回合结算
- **WHEN** 双方完成出手
- **THEN** 按速度决定行动顺序，伤害与治疗即时结算，血条与飘字同步更新

#### Scenario: 五行克制
- **WHEN** 技能属性克制目标属性
- **THEN** 伤害提高并显示「克制」提示；被克制时伤害降低并显示「受制」

#### Scenario: 战斗结束
- **WHEN** 敌方全体气血归零
- **THEN** 结算经验并回到原场景，角色停留在触发位置附近

#### Scenario: 全队战败
- **WHEN** 我方三只灵兽全部失去战斗能力
- **THEN** 显示战败界面，可选择回到最近场景入口并恢复半血，或读取存档

#### Scenario: 遁走
- **WHEN** 玩家选择遁走且判定成功
- **THEN** 退出战斗回到场景；Boss 战不可遁走

### Requirement: 收服与成长
系统 SHALL 允许在战斗中结契敌方灵兽，并驱动等级、经验、技能与队伍管理。

#### Scenario: 结契成功
- **WHEN** 目标气血比例越低且已使用「灵符」时结契判定成功
- **THEN** 该灵兽加入队伍或灵兽录，战斗立即结束并结算经验

#### Scenario: 结契失败
- **WHEN** 结契判定失败
- **THEN** 消耗一次行动，敌方继续行动，界面提示失败原因

#### Scenario: 升级与习得
- **WHEN** 灵兽经验达到阈值
- **THEN** 等级提升、属性成长，达到指定等级时自动习得新术法

#### Scenario: 队伍上限
- **WHEN** 队伍已有 3 只灵兽且再次结契成功
- **THEN** 提示队伍已满，需在队伍界面替换或放归一只

### Requirement: 剧情推进
系统 SHALL 通过对话与 Boss 战推进三段主线，并在结局给出完整收束。

#### Scenario: 对话触发
- **WHEN** 玩家靠近 NPC 或剧情触发点
- **THEN** 弹出逐字对话，可按键推进，对话结束后给予目标提示或道具

#### Scenario: 解锁下一场景
- **WHEN** 击败当前场景 Boss
- **THEN** 下一场景入口开放，存档更新

#### Scenario: 结局
- **WHEN** 击败终局 Boss
- **THEN** 显示结局文本与本次游玩统计（收服数、战斗数、用时），可返回标题

### Requirement: 离线优先存档
系统 SHALL 在未登录状态下将进度写入 `localStorage`，且网络不可用时游戏不中断。

#### Scenario: 自动存档
- **WHEN** 场景切换、战斗结束、进入新剧情节点
- **THEN** 立即写入本地存档，不打断游玩

#### Scenario: 离线游玩
- **WHEN** 玩家在断网或 API 不可用时游玩
- **THEN** 游戏照常运行，仅提示“云端未连接”，不阻塞任何操作

#### Scenario: 存档损坏
- **WHEN** 本地存档解析失败
- **THEN** 忽略该存档并以新游戏进入，同时提示存档不可用

### Requirement: 账号与云存档
系统 SHALL 提供用户名密码注册/登录，登录后自动把存档同步到云端，实现跨设备续玩。

#### Scenario: 注册
- **WHEN** 玩家提交 3-20 位用户名与至少 6 位密码
- **THEN** 创建账号并直接登录，服务端仅存 PBKDF2 加盐哈希，不存明文

#### Scenario: 登录
- **WHEN** 用户名与密码匹配
- **THEN** 返回会话令牌，客户端随后拉取云端存档并与本地比较

#### Scenario: 自动同步
- **WHEN** 已登录且关键节点存档发生变化
- **THEN** 本地先写、随后以 2 秒防抖推送云端，失败静默重试且不影响游玩

#### Scenario: 跨设备续玩
- **WHEN** 玩家在另一台设备登录同一账号
- **THEN** 自动拉取云端存档，并从云端记录的场景与队伍继续

#### Scenario: 双向冲突
- **WHEN** 本地与云端的更新时间不一致
- **THEN** 以较新者为准，并在界面提示“已采用较新进度”，不静默覆盖

#### Scenario: 登出
- **WHEN** 玩家登出
- **THEN** 清除本地令牌，保留当前存档继续单机游玩

### Requirement: 云端部署
系统 SHALL 可通过 Wrangler 部署到 Cloudflare，静态资源与 API 同源，无需额外域名配置。

#### Scenario: 部署后访问
- **WHEN** 执行部署并访问分配的 `*.workers.dev` 域名
- **THEN** 游戏可直接加载，`/api/*` 正常工作，无跨域请求

#### Scenario: 未登录访问 API
- **WHEN** 未携带令牌请求 `/api/save`
- **THEN** 返回 401，客户端降级为本地存档

### Requirement: 水墨视觉与响应式
系统 SHALL 以水墨仙侠基调呈现，并在桌面与移动端均可操作。

#### Scenario: 桌面操作
- **WHEN** 玩家使用键盘方向键 + 回车/数字键
- **THEN** 可完成移动、对话推进与战斗指令选择

#### Scenario: 移动端操作
- **WHEN** 玩家在窄屏设备上游玩
- **THEN** 显示屏幕方向键与可点选的战斗指令，布局不溢出、文字不重叠

#### Scenario: 视觉一致性
- **WHEN** 任意界面渲染
- **THEN** 仅使用宣纸底、墨色层级与灵玉青一种强调色，标题使用宋体字族，无阴影卡片堆叠
