# Checklist

## 视觉与结构
- [ ] 首屏即海报：游戏名是全屏最重的字，不是叠加在卡片里的标题
- [ ] 全站仅有一个强调色（灵玉青），墨色承担层级，无渐变阴影卡片堆叠
- [ ] 四个视图（标题 / 探索 / 战斗 / 结局）职责单一，切换存在明确转场
- [ ] 至少三处有意动效：标题入场、遇敌转场、战斗结算收束

## 探索
- [ ] 方向键 / WASD 可移动，撞障碍无穿模
- [ ] 三个场景可依次进入，出口有解锁条件
- [ ] 遇敌区移动达到阈值后触发战斗，敌方来自该场景灵兽池
- [ ] NPC 对话逐字显示且可推进，结束后给出目标提示

## 战斗
- [ ] 按速度决定行动顺序，双方轮流出手
- [ ] 五行克制影响伤害并有「克制 / 受制」提示
- [ ] 胜利结算经验并回到原场景，位置合理
- [ ] 全队战败可选回入口恢复半血或读档
- [ ] Boss 战不可遁走，普通战遁走有判定

## 收服与成长
- [ ] 结契成功率随目标气血降低与灵符使用而提高，失败消耗回合
- [ ] 升级提升属性并在指定等级习得术法
- [ ] 队伍上限为 3，满员时有替换/放归流程
- [ ] 丹药可在战斗内使用并正确扣减数量

## 剧情与存档
- [ ] 三段剧情按顺序触发，Boss 击败后解锁下一场景
- [ ] 终局 Boss 后展示结局文本与统计，可返回标题
- [ ] 切换场景 / 战斗结束 / 剧情节点自动存档，刷新后可续玩
- [ ] 存档损坏时不崩溃，降级为新游戏并提示

## 账号与云存档
- [ ] 可注册、登录、登出，密码以 PBKDF2 加盐哈希存储，数据库无明文密码
- [ ] 未登录或断网时可完整游玩，仅提示云端未连接
- [ ] 登录后自动拉取云端存档，换设备登录可续玩同一进度
- [ ] 本地与云端更新时间冲突时以较新者为准并提示，不静默覆盖
- [ ] 令牌失效返回 401 时自动降级为本地存档

## 部署
- [ ] `wrangler.jsonc` 正确配置静态资源目录与 D1 绑定
- [ ] 部署后 `*.workers.dev` 可直接加载游戏，`/api/*` 同源可用
- [ ] 建库、建表、部署命令可复现成功

## 适配
- [ ] 桌面键盘与移动端触屏均可完整通关
- [ ] 375px 宽下无横向溢出、无文字重叠
- [ ] 完整通关一次，数值与节奏无明显断层
